## 🧩 About

**Ready or Not Companion** is a curated list of Ready or Not open-source tools:

- **Overlays** — on-screen helpers, layout notes, objective markers, squad status panels
- **Quality-of-Life Helpers** — loadout catalog, map notes, overlay configuration
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Objective Markers — track mission objectives on screen
- Squad Status Panel — monitor teammate positions in single-player study
- Map Notes — annotated floor plans for practice runs
- Playback Review — record and review mission runs

### Wallhack
- Loadout Catalog — browse weapons, gear, and attachments
- Custom Preset Notes — organize equipment loadouts
- HUD Layout Notes — improved visibility of key indicators

### Aimbot
- Practice Mode Notes — segment study on any map
- Movement Notes — chain complex room clears in the editor
- Config Presets — save and switch study configurations
